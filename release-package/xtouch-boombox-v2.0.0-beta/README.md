# 🎵 XTouch Boombox v2.0.0-beta

**Transform your ESP32 into a powerful DIY boombox with 10-band equalizer!**

## 🚀 Quick Start

### **Try the Web Demo**
```bash
cd web_demo
npm install && npm run dev
# Open http://localhost:5173
```

### **What's Included**
- 📱 **Interactive Web Demo** - Full boombox simulation in browser
- 🔧 **ESP32 Firmware** - Ready for ESP32-2432S028R hardware  
- 📋 **Complete Documentation** - Setup guides and feature explanations
- ⚙️ **Configuration Files** - PlatformIO build settings and templates

## 🎛️ Features

### **🎚️ 10-Band Graphic Equalizer**
Individual sliders for frequencies: 60Hz, 170Hz, 310Hz, 600Hz, 1kHz, 3kHz, 6kHz, 12kHz, 14kHz, 16kHz

### **🔊 Bluetooth Audio & Spotify**  
- ESP32-A2DP Bluetooth streaming
- Spotify Connect with device pairing
- Real-time spectrum analysis

### **📊 Enhanced Visualization**
- Main spectrum analyzer with 12-band FFT
- Real-time frequency analysis  
- Clean, optimized interface

## 🛠️ Hardware Requirements

- **ESP32-2432S028R** (Cheap Yellow Display)
- **WIHZI ZK-1001B** amplifier (optional for full audio output)
- MicroSD card for configuration
